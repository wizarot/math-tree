## galaxy.html 视觉美化（呼吸霓虹灯符号）
- 节点上的 SVG 符号渲染逻辑改为「呼吸霓虹灯」效果：
  - 每颗星按坐标计算独立相位 `phase = x*0.021 + y*0.029`，`breath = 0.5+0.5*sin(time*0.0024 + phase)`，避免整齐闪烁、形成自然星海。
  - 用 `globalCompositeOperation = "lighter"` 加色混合叠出霓虹辉光（外层光晕 + 中层 + 亮色管芯高光），光强随 breath 脉动。
  - 配色沿用游戏语义：已点亮=金 `#ffcf4d`、可学=青 `#6ef0ff`（新增 cyan 着色版本）、未解锁=冷蓝微光。
  - `loadSymbols` 预着色新增 `cyan` 版本（`tintCanvas(off,"#7af0ff")`）；symCache 结构加 `cyan` 字段。
- 背景星空新增 26 颗彩色辉光星（径向渐变 halo），呼应霓虹主题。
- 校验：内联 JS 通过 `vm.Script` 语法检查（36358 字符，无错误）。
- 注意：本机沙箱 localhost 与用户浏览器隔离，预览需在项目目录自行起 `python -m http.server` 后访问 localhost（fetch 本地 JSON/sprite 需 HTTP，file:// 会被 CORS 拦截）。

## galaxy.html 性能修复（卡顿 → 流畅）
- 问题根因：原实现每帧对 702 个节点都做 `shadowBlur`（符号三层霓虹 + 已点亮圆盘光晕 + 稀有度外环），`shadowBlur` 是 Canvas 最贵操作，导致页面卡到爆。
- 修复方案：**把发光预烘焙进离屏 sprite，运行时只做廉价 `drawImage`**。
  - 新增 3 张共享「霓虹光球」径向渐变 sprite（`bakeGlowDisk`，gold/cyan/gray，128px，全节点共用，内存极小）。
  - 符号渲染改为：lighter 叠光球（随 breath 缩放+调透明做呼吸）+ 核心符号 + 白色管芯，零实时模糊。
  - 已点亮圆盘去掉 `shadowBlur`（光晕改由符号霓虹承担）；稀有度外环改用 `lighter` 双层描边模拟辉光，去掉 `shadowBlur`。
  - 仅保留 `shadowBlur` 在选中/悬停圆盘（1~2 节点）和邻居边（少量），开销可忽略。
- 结论：批量节点的实时 `shadowBlur` 全部移除，每帧仅约 3000+ 次廉价 drawImage，无实时模糊。
- 复用价值：这是 Canvas 大量发光节点的通用性能模式（烘焙 glow sprite 代替 per-frame shadowBlur），值得沉淀为 skill。
- **用户已验证**：在本地 `python -m http.server` 起的 `http://127.0.0.1:8000/galaxy.html` 上确认效果满意、基本不卡顿，优化方案有效。
