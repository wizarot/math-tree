# 2026-08-11 数学天赋星图产品视频（真实交互录屏版）

## 方案变更（用户要求）
- 视频必须展示**真实交互操作**（鼠标拖拽/滚轮缩放/点击节点看前序后续/中国课标过滤/领域+年龄过滤/点亮节点/双视图切换/控件总览），不能用静态截图。
- 时长不设固定值（用户明确"需要多长就多长"），由内容自然决定。

## 技术方案
- **录屏**：Playwright 驱动系统 Edge（`executablePath` 指向 `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`）的 `recordVideo` 录制 1920x1080 实机操作；脚本 `remotion-videos/scripts/record_clips.mjs` 录 C0–C8 九段到 `public/assets/clips/`。
- **ffmpeg hack**：Playwright recordVideo 缺 `ms-playwright/ffmpeg-1011/ffmpeg-win64.exe`，把系统 ffmpeg（Captura 5.0.1）拷贝到该路径解决（`C:\Users\zhang\AppData\Local\ms-playwright\ffmpeg-1011\ffmpeg-win64.exe`）。
- **Canvas 节点点击**：星图是 Canvas 无 DOM 节点，用全局 `selectNode(id)` 把节点居中到 (960,540)，再真实 `mouse.click(960,540)` 命中（避免脆弱的坐标反算）。其余过滤/点亮/前序后续/有序页均为真实 DOM 点击。
- **配音**：`scripts/generate_audio.py`（edge-tts 晓晓 +30%），11 段，总≈96s，输出 `durations.json`。
- **Remotion 工程重写**：`durations.ts`（import audio+clips 两个 durations.json，每幕时长=max(配音,录屏总时长)+pad，动态算 TOTAL_FRAMES）、`components.tsx`（Subtitle/CardScene/ClipScene/Fade）、`VideoComposition.tsx`（11 幕 Sequence 串联）。`gen_durations.mjs` 录制后量 clips 时长写 `clips/durations.json`。
