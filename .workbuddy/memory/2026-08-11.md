## 纠错（commit 41ba0aa）—— 雪碧图用法的正确姿势
- **用户纠错**：`sidebar_bg.png` 不该从雪碧图里切出来；正确做法是把 `items.png` 整张作为 `background-image`，用 `background-position` 抠子图。
- **雪碧图（CSS Sprite）的本意**：一张大图容纳多个 UI 元素，CSS 通过 `background-image: url(big.png)` + `background-position: -x -y` "开窗"显示子图，**不切图、不生成独立文件**。
- **本次实现**：`#sidebar.glass` 改为 `background: radial-gradients, url("assets/items.png") -60px -80px no-repeat, #46342B;`。面板位于 items.png (60,80)-(490,540)，取负偏移把左上角对齐到侧栏原点。
- **拼接性判定**（关键）：边带边框的面板**不可 `repeat`**。检测方法：取 (top,bot,left,right) 各 4px 边缘均值 RGB，比较 top↔bot 距离（>20 即不可纵向平铺）。本面板上下色差 128.7，确认 `no-repeat`，下沿用 `background-color #46342B` 补暗皮革（与面板底沿 RGB(70,52,43) 匹配，无痕）。
- 删除 `assets/sidebar_bg.png`（冗余切片）。
- **辉光球 orb_*.png 仍保留为独立文件**：作为 18px 小图标，从 2908×1440 雪碧图用 `background-image` + `background-size` 缩放抠图时计算复杂（需同步缩放 position），且 orbs 是离散小元素，切出独立 PNG 反而清晰。这与"主面板纹理必须用雪碧图背景"不冲突。

## 顶部 HUD 底图（commit d4a0739）—— 用 AI 出图铺顶条
- **素材**：`assets/top.png`（2910×504，5.78:1 超宽高比）—— 古铜皮革面板 + 四角铜花角 + 金描边 + 右侧分隔栏。
- **HUD 现状**：`#hud` 固定 `top:12px; left/right:12px`，宽 = 视口−24px（~1200–1900），高由 `padding:10px + 内容` 驱动（~36–48px）。图片宽高比 5.78 vs 盒子 ~25，差距大。
- **铺法选择**：`background-size: 100% auto; background-position: center top;` —— 宽度填满、高度按图片比例（自动算 ~HUD width × 0.17），仅显示顶部 ~52px 条带，刚好露出图的上沿金边 + 两侧铜花角 + 皮革纹理；下半被 HUD 自身裁掉（无花纹的素皮革），看起来就是连续的顶条。
- **细节**：`min-height:52px` 固定高度防止内容挤压；`border-radius:6px`（不裁铜花角）；`backdrop-filter:none`（去掉磨砂避免压糊图）；保留 CSS `border:1px solid var(--border)` 外框（图本身已有金边，两者叠成双线）。
- **不选 `100% 100%`**：竖向压缩会把铜花角压扁。**不选 `cover`**：会按 height 缩放，整图成 277×48 的细条居中，两侧大面积空白。
- **结论**：超宽高比的装饰面板做顶条，最稳的是"按宽度等比缩放 + 取顶部条带"。
